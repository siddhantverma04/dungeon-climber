
# Dungeon Climber 
A 2D platformer built in Godot 4 as part of Hack Club's Stardance.

### Features
- Custom Physics: Smooth left/right movement, jumping, and gravity.
- Level Mechanics: Climbable ladders, moving platforms, and interactive chests.
- Hazards & Progression: Floor spikes that trigger health loss, automatic scene resets on death, and an exit door to complete the stage.
- Camera Limits: Dynamic camera positioning with boundary limits to keep focus on the stage.

### Built With
- Engine: Godot 4 
- Language: GDScript
- Tutorials & Assets: Inspired by Coco Code tutorials and custom/sourced tilemaps.

### How to Run / Play
- Go to this itch.io link [https://hacr7.itch.io/dungeon-climber](https://hacr7.itch.io/dungeon-climber)
- Play the game!

### Controls
- WASD
- Arrow keys
- Space to jump
